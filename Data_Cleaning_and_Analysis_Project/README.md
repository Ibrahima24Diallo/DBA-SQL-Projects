## Data Cleaning Project – Worldwide Layoffs (2020–2023)



This project focuses on cleaning, exploring, and analyzing real-world layoff data from well-known companies worldwide between 2020 and 2023 using MySQL.



After cleaning the dataset to remove duplicates, standardize values, and handle missing data, I performed data exploration and analysis to uncover key insights, including:



* Total layoffs by company, industry, and country



* Layoff trends by year and month



* Companies with the largest layoffs or 100% reductions



* Industry rankings based on the number of layoffs



* Cumulative layoffs over time using window functions



* Use of views to simplify recurring analysis queries



* Stored procedures to automate common reporting tasks



* Triggers to help maintain data consistency and integrity



This project highlights my ability to work with messy real-world data, apply structured data-cleaning techniques, and use SQL effectively to prepare datasets for reporting and further analysis.
