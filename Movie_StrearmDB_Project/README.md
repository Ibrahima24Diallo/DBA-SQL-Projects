# Movie Streaming Database (SSMS / SQL Server)

In this project I gathered data from few family members and friends to simulate a real-world movie streaming platform.
The project demonstrates skills in:

- Database design

- SQL Server development

- ERD modeling

- Complex SQL queries

- Stored procedures

- Index optimization

- Many-to-many relationships

- Data analytics using SQL

# Features of the project

- Users & subscriptions

- Movies, genres & relationships

- Tracking Watch history 

- Analyze Popular Movies
