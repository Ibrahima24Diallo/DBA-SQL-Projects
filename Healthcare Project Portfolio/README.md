# Project Title: Healthcare Patient Visit Database 
Relational Database: MySQL

In this project I modeled how a real-world healthcare clinic system words.

The project demonstrates skills in:

* Database design using MySQL
* Many-to-many relationships (i.e Doctors and their Specialties)
* Revenue Reporting 
* CTEs, window functions, aggregations
* Index Optimization
* Views, Stored Procedures


# Questions I tried to answer:

* Most profitable doctors
* High Value Patients
* Frequency of appointment
* Track Payment Status
* Doctors based on their Specialties
