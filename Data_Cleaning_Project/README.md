# Data Cleaning Project – Worldwide Layoffs (2020–2023)

# 

# This project focuses on cleaning and preparing a real-world dataset containing layoff information from well-known companies around the world between 2020 and 2023. The goal was to transform raw, inconsistent data into a reliable and analysis-ready format using MySQL.

# 

# The dataset initially contained duplicate records, inconsistent formatting, missing values, and unnecessary fields. To improve data quality and accuracy, I performed the following steps:

# 

# Removed duplicate records to ensure each layoff event was represented only once

# 

# Standardized the data by cleaning company names, locations, dates, and change the date column's data type for consistency

# 

# Handled null and blank values by updating, validating, or removing records where it was appropriate to do so

# 

# Removed unnecessary columns and rows to keep the dataset focused and efficient for analysis

# 

# This project highlights my ability to work with messy real-world data, apply structured data-cleaning techniques, and use SQL effectively to prepare datasets for reporting and further analysis.
